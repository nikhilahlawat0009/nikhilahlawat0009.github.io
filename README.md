## Projects

**[AI Image Detection](https://github.com/nikhilahlawat0009/AI_generated_image_tracker)** decides whether a picture was generated by a machine, using three independent checks that vote, and a Claude agent that explains the verdict. 96.4% accurate on images it has never seen, and it says when it is unsure instead of guessing.

**JARVIS** is a voice assistant for my Mac, built on an agent loop I wrote by hand. Three agents split along a trust boundary, so the one that reads news off the internet shares nothing with the one that can control the machine. Private repository.

**[Production-Grade Retrieval Platform](https://github.com/nikhilahlawat0009/production-rag)** searches financial documents by combining keyword and meaning-based search, then reranking what comes back. 100% recall@5 and 180ms at the 95th percentile, measured against 20 known-answer queries.

**Document Processing Pipeline** turns a 274-page annual report into something you can query, with every extracted fact traceable back to the page it came from. Private repository.

**[SmartInvest](https://github.com/nikhilahlawat0009/smartinvest)** reads UK filings and market signals and explains them in plain English, including how much of a share price is value and how much is enthusiasm.

Older work: [LSE Stock Prediction](https://github.com/nikhilahlawat0009/LSE-Stock-Prediction), [London Weather App](https://github.com/nikhilahlawat0009/London-Weather-Pipeline), [COVID-19 Analysis](https://github.com/nikhilahlawat0009/Covid19Analysis), [Customer Segmentation](https://github.com/nikhilahlawat0009/Customer-Segmentation-and-Market-Analysis).
